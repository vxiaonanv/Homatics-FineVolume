# Homatics FineVolume 1.0

Android TV 14 compatibility diagnostic prototype. No root, no system modifications.

This build reports actual Android media stream volume levels, tests standard volume adjustments, and offers an HDMI-CEC settings shortcut. Overlay options are saved for future development; global 100-step control, boot service, and system volume overlay replacement are **not implemented**.

Build via GitHub Actions > Build Android APK > Artifacts. Debug APK is signed with a development key.
